# Datasets — online feeds for experiments

The IP is "fed by online datasets as experiments": firmware streams samples into the accelerator and reports learning progress. All of these are downloadable, byte-oriented, and small enough to embed/convert to hex memory images.

## Image classification (MNIST family — the classic online-learning experiments)

All three are 28×28 grayscale, 10 classes, 60k train / 10k test — **drop-in interchangeable**, same format. The IDX byte format is trivial to convert to `$readmemh`/hex streams for firmware.

| Dataset | Size | Links |
|---|---|---|
| **MNIST** (digits) | ~11 MB (gz) | http://yann.lecun.com/exdb/mnist/ ; TFDS: https://www.tensorflow.org/datasets/catalog/mnist |
| **Fashion-MNIST** (clothing) | ~26 MB (gz) | https://github.com/zalandoresearch/fashion-mnist (direct S3 links + MD5 checksums in README); paper arXiv:1708.07747 |
| **Kuzushiji-MNIST** (hiragana) | ~18 MB (gz) | https://codh.rois.ac.jp/kmnist/ ; https://github.com/rois-codh/kmnist (also K49: 49 classes, KKanji: 3832 classes) |

Why these: Nielsen's book trains MNIST with plain SGD — the exact algorithm our accelerator will implement, so results are directly comparable to a reference software model. Fashion/Kuzushiji test generalization (harder than MNIST — a good "is the learner actually learning?" check).

## Signal traces (for LMS / adaptive-filter experiments)

For the LMS-family direction: streamed sample pairs (input x(n), desired d(n)) for system identification, noise cancellation, echo cancellation.

- Synthetic traces can be generated by a small Python script (sine + noise, unknown FIR plant) — deterministic, self-contained, no download needed.
- Published test vectors: the LMS papers in papers.md §2 used speech signals / ECG databases (e.g., NiFECG in the FECG extraction paper) — real-data option if we want non-synthetic traces.

## Other candidates noted in the surveys

- **CIFAR-10** (32×32 color, 10 classes) — used by most FPGA training papers (EF-Train, IJCAI 2020, RepVGG) as the standard benchmark; heavier than MNIST-class for a simple IP but fine as a stretch experiment.
- **Wake Vision** — large-scale person-detection dataset built for TinyML (mentioned in arXiv:2506.18927) — representative of a real always-on sensing task.
- **ECG databases** (e.g., from PhysioNet) — used with LMS-FECG hardware; a realistic "learn from a live sensor stream" demo.

## Conversion plan (for firmware experiments)

1. Download IDX files → Python script converts to per-sample hex rows (e.g., 784 bytes of pixels + 1 byte label per row, fixed-point scaled).
2. Embed as `$readmemh`-loadable arrays or stream over UART via firmware.
3. Firmware drives: reset → load initial weights → stream samples (or a live sub-stream) → read accuracy/error counters → print experiment results.
